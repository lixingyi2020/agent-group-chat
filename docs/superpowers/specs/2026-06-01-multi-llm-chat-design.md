# Multi-LLM Group Chat — Design Spec / 多 LLM 群聊 — 设计规范

**Date:** 2026-06-01 | **Status:** Implemented / 已实现

## Overview / 概述

A web-based chat application where a user converses with multiple AI LLMs in a single group-chat conversation. LLMs can talk to each other — they can @mention one another, respond autonomously based on configurable participation modes, and build on each other's responses.

一个基于 Web 的聊天应用，用户可以在一个群聊对话中与多个 AI LLM 交流。LLM 之间可以互相交谈 — 它们可以 @提及彼此，根据可配置的参与模式自主回复，并在彼此的回复基础上继续讨论。

## Core Decisions / 核心决策

| Area / 领域 | Decision / 决策 |
|-------------|-----------------|
| Interaction model / 交互模式 | Group chat — user + LLMs as equal participants / 群聊 — 用户与 LLM 平等参与 |
| LLM participation / LLM 参与 | Configurable per LLM: @mention (exclusive), always-on, probabilistic / 每个 LLM 可配置：@提及（排他）、始终在线、概率参与 |
| Mention behavior / @提及行为 | When specific LLMs are @mentioned, ONLY those respond; @Everyone triggers all / @特定 LLM 时仅其回复；@所有人 触发全部 |
| LLM connectivity / LLM 连接 | User brings own API keys (BYO) / 用户自带 API 密钥 |
| Deployment model / 部署模式 | Single FastAPI process + SQLite / 单 FastAPI 进程 + SQLite |
| Tech stack / 技术栈 | Python FastAPI + HTMX + Jinja2 + SQLite + SSE |
| Message delivery / 消息投递 | SSE streaming for live token-by-token; Markdown rendering via marked.js / SSE 流式逐字输出；Markdown 渲染 |
| LLM context / LLM 上下文 | Full conversation history (empty messages filtered) / 完整对话历史（过滤空消息） |
| Persistence / 持久化 | SQLite, conversations survive restarts / SQLite，对话跨会话保存 |
| Users / 用户 | Single-user, no auth / 单用户，无认证 |
| Response length / 回复长度 | 200 chars default, configurable per LLM / 默认 200 字符，每个 LLM 可配置 |
| Language / 语言 | Simplified Chinese default, English switchable / 简体中文默认，可切换英文 |
| Title generation / 标题生成 | Auto-generated by designated LLM, manually editable / 指定 LLM 自动生成标题，可手动编辑 |

## System Architecture / 系统架构

Single FastAPI process using asyncio. No Redis, no background workers.

单 FastAPI 进程，使用 asyncio。无需 Redis，无需后台 Worker。

```
Browser (HTMX + SSE) ──HTTP──▶ FastAPI ──SQL──▶ SQLite
                                   │
                                   └──HTTPS──▶ OpenAI / Anthropic / Google / DeepSeek / Zhipu / Kimi
```

## Features / 功能

- **Multi-LLM group chat** — User and multiple AIs in one conversation / 用户与多个 AI 在同一对话中
- **@mention system** — @ specific LLMs (exclusive response) or @Everyone (all respond) / @特定 LLM（排他回复）或 @所有人（全部回复）
- **Configurable participation** — mention_only, always, probabilistic per LLM / 每个 LLM 可配置参与模式
- **LLM-to-LLM chains** — LLMs @mention each other, depth-limited / LLM 之间可互相 @提及，有深度限制
- **SSE streaming** — Token-by-token live output via Server-Sent Events / 通过 SSE 逐字实时输出
- **Markdown rendering** — Code blocks, lists, tables, blockquotes via marked.js / 代码块、列表、表格、引用等
- **Auto-title generation** — Designated LLM summarizes conversations / 指定 LLM 自动生成对话标题
- **Inline title editing** — Edit titles from header or sidebar / 可从标题栏或侧边栏编辑标题
- **Conversation management** — Create, delete conversations / 创建、删除对话
- **LLM config management** — Add, edit, delete LLM configurations / 添加、编辑、删除 LLM 配置
- **i18n** — Simplified Chinese (default) + English / 简体中文（默认）+ 英文
- **BYO API keys** — Encrypted at rest with Fernet / API 密钥 Fernet 加密存储
- **@mention autocomplete** — Dropdown when typing @ / 输入 @ 时弹出自动补全
- **Clickable LLM list** — Header status shows all LLM names / 点击标题栏状态查看所有 LLM 名称
